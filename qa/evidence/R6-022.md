# R6-022 · 常驻查询、紧凑结果与渐进覆盖（PASS）

| 项 | 值 |
|---|---|
| 实现 | `src/shared/query-jobs.js`（切片扫描、预算暂停、取消、续查、结果缓存）+ `engine-core.startQuery` |
| Node 测试 | `tests/r6/query-jobs.test.cjs` → **8 项** |
| 页面实测 | 30 次查询 p50 **≈300 ms**、p95 **378.6 ms**，无 1.8 s 误杀（`M2-gate/local-vertical.json`） |

## 语义

- 未完成时 `relation=at_least`、`coverage.complete=false`、`order_final=false`；**只有扫描完才允许 `exact` 与"0 条"**。
- 30 秒活动预算到期 → `paused` + `resume_token`，**不是错误**；`resume` 从同一扫描位置继续，同一快照。
- 取消 → `relation=unknown, matched=null`，并给出已扫描块数。
- 结果只带一页 ordinal（≤ limit）与计数；零命中不产生逐记录数组。
- 缓存键含 namespace/文件/代次/签名/等级/时间范围；代次变化即失效。
- 按块取数：`startQuery` 不再整代预载，`fetch(from,count)` 只读即将扫描的块。

## 边界

- 时间线/排序的 `order_final` 在多文件合并（`R6-0xx` Combined Provider）前恒为单文件真值。
- 搜索结果页目前只取第一页 ordinal（200），后续翻页属 `R6-027` 的游标扩展。
