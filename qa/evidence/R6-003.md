## 关键发现

1. `src/style.css` 首行即声明 *Unify Design v1.0.1 · tokens scoped to `.ud-app`*，并与 kit `tokens.json` **47/47 一致**。R6 的任务不是"引入设计系统"，而是"不破坏它"。
2. 产品覆盖集中在单行（`style.css:27`）：`--ud-muted` 加深、`--ud-control-h:32px`、`--ud-radius-lg:8px`，外加 density/contrast/coarse 变体。属局部 variant，符合 unify-design 的"局部变体取代共享原语变更"原则。
3. **外壳绕过令牌**：`--ud-sidebar-w:234px` / `--ud-topbar-h:54px` 声明存在，但 `.lb-app` 硬编码 `208px / 52px`，宽屏 224、窄屏 186。三处值不统一，需产品决定是否接线。
4. 桌面首屏数据区 600/768 ≈ 78%，toolbar 在 ≥768 宽度恒为 1 行——满足"信息密度优先、时间范围不独占一行"的既有结论。

## 闸门

`visual_baseline.py` 在以下情况返回非零：

- 抽屉打开后阅读区/时间线 `dx` 或 `dw` > 1px；
- 首行锚点位移 > 2px；
- Esc 未关闭抽屉；
- 宽度 ≥768 时 toolbar 折成多行。

当前五档视口全部 `exit 0`。后续 UI 票（`R6-021/025/027/028/029/048/056/067/068/075/079/080/081/082/083`）必须复用同一脚本与同一固定输入。
