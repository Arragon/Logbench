# R6-079 · 跨来源全局时间筛选与可保存范围视角

## 交付

| 文件 | 职责 |
| --- | --- |
| `src/ui/global-time.js` | 双区弹窗：左日期/时间/小数秒 + 最近/收藏；右本机/私有/共享层级多选树；draft 与 applied 分离；视角保存/恢复 |
| `src/r6-app.js` | `时间范围` 入口在工具条内（不独占一行）；应用后以 `scope` 模式渲染阅读区；每个文件用独立的子 Provider |
| `src/r6.html` / `src/r6.css` | 弹窗容器与紧凑样式（全部复用 `--ud-*` 令牌） |
| `tests/r6/global-time.test.cjs` | 12 项：目录包含后代、单文件排除、单文件选择、部分选择、范围校验、小数秒、视角重解析 |
| `qa/r6/global_time.py` | 真实浏览器 UI 驱动，14 项 |

### 关键语义

- **draft 与 applied 分开。** 编辑弹窗不改变阅读区；只有"应用范围"提交，`取消` 把草稿还原到已应用状态。
- **目录是"稳定引用"，不是快照。** 保存视角记录目录 id 与文件 id；再次载入时重新解析后代 —— 新增文件自动纳入，消失/撤权的条目进入 `missing` 并提示，**不会替换成样例**。
- **时间输入按 UTC 解析并在界面上写明。** 小数秒 1–9 位，起止闭区间；起始晚于结束直接拒绝并禁用应用，不静默交换。
- **加载不与输入打架。** 弹窗加载来源是异步的；若用户在加载期间已经改过时间，迟到的加载不会把范围/选择覆盖回去（`touched` + `openToken`）。
- **入口在工具条里。** 1366×768 实测工具条高度 40px，阅读区没有被推下一行。

## 已知限制

- 阅读区"范围模式"一次只装一个窗口（每文件 ≤400 条），没有"继续加载"。见 B-042。
- 无时间戳文件在时间模式下被排除，界面只给计数提示，不提供"按出现顺序浏览"的替代视图。见 B-043。
- 不支持时区换算（按设计不猜），跨时区文件需要用户自行换算后输入 UTC。
- 视角集合存在本机 `localStorage`，不随身份同步；换浏览器/清缓存会丢失（与 R5 的个人设置一致）。
