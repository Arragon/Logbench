# R6-060 · 受控传输适配器骨架与能力探测合同

> Linear：`INH-2303` · 里程碑 M6 · 状态：**已实现**

## 变更
- `server/collectors/base.py`：`Capabilities`（supported/unverified/unsupported +
  `followCapable`）、`ProbeResult`（绑定 configRevision 与 fingerprint、过期判定）、
  `Adapter`（probe/list/stat/read_range/open_snapshot/cancel/close）、错误分类
  `retry`/`manual`/`file`/`fatal`、注册表与 `availability()`（缺工具 → unavailable）。
- `server/collectors/process.py`：`ToolLocator`（路径 + 版本可追溯）、`Runner`、
  `WindowedReader`。
- `server/collectors/rclone.py`：`:sftp,host=…,user=…,port=…:` 形式的即时后端字符串，
  不写 `rclone.conf`、不接受 `--config`；lsjson/stat/cat/copyto 封装。

## 验证

```bash
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_adapter_contract
# Ran 10 tests ... OK
```
覆盖：四种协议已注册；未知协议 `unsupported`；rclone 缺失时 `tool_missing` 且
标记 manual；`list()` 不返回空成功；`followCapable` 需 `append_contract=declared`；
probe 携带修订与指纹；错误分类；`read_bounded` 超限拒绝。
