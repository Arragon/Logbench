# R6-063 · HTTP(S) Range、验证器与安全快照读取

> Linear：`INH-2306` · 里程碑 M6 · 状态：**已实现，本机真实 socket 覆盖**

## 变更
- `server/collectors/http_range.py`：`HttpTransport`（TLS 默认校验、可选组织 CA、
  逐跳重定向准入并跨主机丢弃 Authorization、响应大小上限）与 `HttpRangeAdapter`
  （HEAD/GET 探测、强/弱 ETag、If-Range、206/200/416 语义、窗口复用）。

## 验证（真实 loopback HTTP 服务器，非 mock）
```bash
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_http_range
# Ran 17 tests ... OK
```
覆盖：206 正确范围；忽略 Range 的 200 → `range_read=unsupported` 且预检 not ok；
错误范围的 206 → `generation_changed`；中途 offset 收到 200 → 拒绝拼接；
截断 body → `partial_read`；416 结尾返回空块、长度不符 → `generation_changed`；
弱 ETag → 身份降级并给出警告；404/401 区分；Bearer 凭据只出现于请求头且不进入错误；
跨主机重定向被准入拒绝，放宽后目标端确认未收到 Authorization。
证据：`qa/evidence/R6-063/`（JSON 由测试输出，见 `http-range.json`）。

## 已知限制
每个 8 MiB 窗口一次 HTTP 请求，未做 keep-alive 复用；大文件顺序读 = N/8 次请求。
