# R6-037 · 分片索引与读取

## 交付

- `server/indexing/shards.py`：每 (file, generation, signature) 一个 SQLite 分片；
  `commit_batch` 单事务写记录 + 水位；`INSERT OR REPLACE` 按 ordinal 幂等，
  重放收敛而不重复。
- 读取面：`page/get/get_by_id/seek_line/seek_byte/time_range/timeline/checkpoint/
  query_plan`，分页上限 2000。
- 列补充：`pid/tid/src/src_line`（规则层离线重算需要，见 R6-038），
  分层表 `layer_versions/rule_rows/rule_timeline/search_postings`。
- 网络盘拒绝：`assert_local_fs` 拒绝 `/Volumes` 与 NFS/CIFS/SMB 挂载点；
  `journal_mode=DELETE` 默认（目标机 SQLite 3.38 不支持 WAL 安全断言）。

## 验收命令

```
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_shards -v
```

13 项全绿：单事务提交、重放幂等、分页上限、seek 行/字节、时间范围把未定时记录
排在末尾、页大小 20/50/100/150 校验、`query_plan` 走索引、网络盘拒绝。

## 备注

修复过的真缺陷：`time_range` 的 `ORDER BY ts_key` 让 NULL 排在最前，时间视图
会以「没有时间戳」的行开头；改为 `ORDER BY (ts_key IS NULL), ts_key, ordinal`。
