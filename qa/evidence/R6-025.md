# R6-025 · 渐进搜索 UI、IME、取消与结果状态（PASS，取消/续查只到控制器层）

| 项 | 值 |
|---|---|
| 实现 | `src/ui/search-controller.js` |
| 测试 | `tests/r6/search-and-highlight.test.cjs` 中的搜索 7 项 |
| 页面实测 | 30 次查询 p95 **378.6 ms**；"0 条"只在完整扫描后出现（Gate 断言） |

## 文案与状态的对应（都有测试）

| 状态 | 文案 | relation |
|---|---|---|
| 运行中 | "搜索中，当前显示上一份结果：…" | at_least（旧结果） |
| 未完成 | "至少 N 条（已扫描 34%）" | at_least |
| 完成 | "N 条" | exact |
| 取消 | "已取消（已扫描 34%），结果不完整" | unknown |
| 预算暂停 | "已暂停（已扫描 10%），至少 90 条" | at_least + resumable |

## 行为

- 250 ms 去抖；Enter 立即提交；`compositionstart` 期间不提交，`compositionend` 后提交。
- 每次条件生成 `query_version`；旧回包被丢弃，慢的旧请求无法覆盖新结果。
- 候选文件在提交时读取（`getBaseSpec`），切换文件后不会静默搜旧文件。

## 未做

- 页面上的取消按钮只对处于 `searching`/`paused` 的查询可见，但没有"继续"按钮接线（控制器支持 `resume`，页面缺入口）。
- 多规则 OR/AND/分标签切换未做 UI（AST 支持 `joiner`）。
