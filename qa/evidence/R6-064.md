# R6-064 · HTTP 目录清单、显式 URL 与代次 manifest 发现

> Linear：`INH-2307` · 里程碑 M6 · 状态：**已实现**

## 变更
- `server/collectors/http_listing.py`：`logbench.manifest/1` 清单（generation、sealed、
  files[path,size,etag,sha256]）、显式 URL、HTML 目录索引三种模式；
  未知 schema/字段拒绝、条目数上限、路径穿越与外部链接丢弃、重复链接去重、
  无可用链接返回 `unsupported` 而非空目录。

## 验证
```bash
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_http_range.HttpListingTests
# 5 tests ... OK（含在 17 项内）
```
覆盖：清单解析出 generation 与文件；未知字段拒绝；无清单 → 能力缺失；
HTML 索引保留本地链接、丢弃外链与 `../`、重复只出现一次、目录标记；
无可用链接 → `unsupported`；预检把发现能力与范围能力分别报告。
