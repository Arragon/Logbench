## 剪枝何时被拒绝（都有断言）

| 情形 | 处理 | 原因 |
|---|---|---|
| 正则项 | 不剪枝 | `a.*b` 可以匹配任何 gram 都缺失的文本 |
| 项短于 gram | 不剪枝 | 索引只存一种 gram 长度，短项没有可表示的证据 |
| 大小写不敏感的非 ASCII 项 | 不剪枝 | `"ΟΣ".toLowerCase()` 是 `"ος"`，折叠会漏掉真正的 `Σ` |
| 大小写不敏感 ASCII 项 | 用折叠 gram | ASCII 小写对 ASCII 子串是同态 |
| 大小写敏感 / 无大小写（CJK、数字） | 用原始 gram | 精确子串必然带来相同的 gram |
| gram 集被截断 | 不剪枝 | 排序前缀不能证明"不存在" |
| 块内时间戳不完整 | 不按时间剪枝 | 缺失时间不等于区间外 |

跨块词：gram 建在 `blockText + nextBlockPrefix(n-1)` 上，`ener|gy` 这类被切开的词仍可在起始块命中。
