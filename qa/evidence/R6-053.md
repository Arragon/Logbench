# R6-053 · 根目录安全访问、挂载身份与离线写保护

**状态**：完成（POSIX 实测；单元可注入身份）

## 变更

| 文件 | 变更 |
|---|---|
| `server/storage/guard.py` | 新增。路径规范化、逐段 `lstat` 拒绝符号链接、`O_NOFOLLOW` + `dir_fd` 打开、realpath 越根复核、`volume_id`+sentinel 挂载身份、离线/停用判定、探测、可逆名称映射 |
| `server/storage/catalog.py`、`trash.py`、`bindings.py` | 所有读写都经由 guard 解析，不再各自拼路径 |

## 行为要点

- `STORAGE_ROOT_OFFLINE` 细分 `missing` / `not_a_directory` / `became_symlink` / `volume_changed` / `sentinel_missing` / `sentinel_mismatch`；写入一律拒绝，读取保留登记。
- 保留 R5 的 symlink 限制与 `data/` 围栏；未新增 sudo/chmod/mount 行为。
- 打开文件走 POSIX 描述符相对访问（`O_DIRECTORY|O_NOFOLLOW` + `fstat` 校验常规文件），缩小检查与使用之间的竞态窗口。
- 控制字符、`%`、超长组件映射为可逆物理名（`encode_component` / `decode_component`），超长时保留 digest 后缀避免截断碰撞。

覆盖：`../`、绝对路径、反斜杠、盘符、控制字符、隐藏段、根内 symlink、目录 symlink 穿越、打开目录被拒、sentinel 缺失/volume 变化/根变 symlink/根目录消失、probe 幂等且 0600、无写权限时 `unauthorized`、名称映射可逆与长名不碰撞。

## 限制

- Windows 下 `O_NOFOLLOW` 不可用，走 realpath 复核路径；未在 Windows 实测。
- 未在真实卸载/换盘场景验证（Gate 2d 标 BLOCKED）。
