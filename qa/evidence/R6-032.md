# R6-032 · 迁移与备份

## 交付

- `server/migrations/__init__.py`：`SCHEMA_VERSION = 5`，五步 expand-only 迁移
  （control-plane-entities / cache-and-index-publication / query-snapshots /
  job-actions / layered-cache-registry）。
- 失败语义：步骤 checksum 变化 → `migration_checksum_changed`；库版本高于代码 →
  `schema_too_new`；版本缺口 → `migration_gap`；迁移前 `_backup_once` 生成
  `*.pre-r6-<n>` 备份。
- 版本表独立提交：`schema_migrations` 先单独提交，避免步骤失败时把版本记录一起回滚。

## 验收命令

```
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_migrations -v
```

11 项全绿，覆盖：全新库到最新版、重复 apply 幂等、checksum 变更拒绝、库过新拒绝、
缺口拒绝、备份只做一次、事务失败后版本不前进、期望表齐全（含
`layer_versions`/`layer_pointers`/`layer_pins`/`layer_events`）。

## 备注

新增的第 5 步只加表，不改 v1 表结构；`layer_versions` 的唯一索引包含 `owner`，
因为缓存版本按 principal 隔离（见 R6-038），同一签名不同 principal 不能互相覆盖。
