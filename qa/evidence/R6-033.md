# R6-033 · 任务控制面

## 交付

- `server/models.py`：`TASK_TRANSITIONS` / `QUERY_TRANSITIONS` 与
  `contracts/r6/state-machine.json` 逐项一致，`assert_transition` 在写入前校验。
- `server/jobs/repository.py`：`create(action_key)` 幂等、`claim(ttl)` fencing 单调、
  `checkpoint` 与 `finish` 同事务校验租约、`reclaim_expired` → `paused` + `lease_expired`
  （崩溃可恢复，不误判失败）。
- `server/jobs/service.py`：`action` 通过 `job_actions` 实现 `actionId` 幂等；
  `pause` 仅允许 `uploading`；`retry` 建新任务；他人任务一律 `unknown_job`。
- `server/app.py`：`/api/v2/jobs` 路由，`LeaseError` → HTTP 状态映射。

## 验收命令

```
env -u PYTHONPATH ~/.local/bin/python3.9 -m unittest tests.test_r6_jobs -v
```

20 项全绿：幂等创建、租约互斥、过期接管、fencing 单调、非法迁移拒绝、越权 404、
CSRF 校验、审计不含原文。

## 备注

修复过的真缺陷：`claim` 曾用「是否在跑」判断重复计数，导致同一 principal 的
并发任务被反复准入；改为只统计 `running`，排序键加入 `running_for(principal)`。
