# 采集中心重设计 · 待确认预览

日期：2026-11-08。范围：`/r6` 的采集中心、详情、新增/编辑向导、存储设置、资源设置。状态：交互预览已验证，尚未批准或实施到生产。

当前用户要求取代此前文档中“严格复制旧原型”的视觉约束：简洁、成熟、紧凑、高效，并删除解释性废话。功能与真实领域契约继续保留。

## 设计决策

- 继续使用项目现有 Unify Design tokens、系统字体、SVG 图标、原生控件和 dialog，不引入框架、外部字体或新组件库。
- 采集中心的页面头与四个页签合成一行；搜索、状态筛选与刷新组成第二行。页面名称由全局面包屑承担，不再重复大标题。
- 远程日志源采用六列：日志源、目录/存储位置、同步状态、归档量、索引覆盖、操作。名称和连接、目录和位置成组呈现；数值右对齐；未建立索引不显示虚假的 0% 或 100%。
- 长路径在列表中截断，点对象名后可在详情中读取完整值；不依赖 hover。详情悬浮，不挤压列表宽度。
- 状态使用图标、文字及语义色。异常原因保留，编辑与恢复入口靠近对象。
- 正常列表只保留一个添加入口。空列表、无匹配、连接失败、加载中和只读分别呈现。
- 新增/编辑保留“连接 → 目录映射 → 采集策略 → 预检”。删除教学式右栏、原理介绍、接口名、硬件配置建议和重复的可靠性说明。必要安全约束、访问范围、历史缺口、迁移限制、错误及未保存离开提示保留。
- 桌面控件 32px，主文字 13px、辅助文字 12px；表单 36px。手机操作约 40–42px，表单使用全屏对话框；表格在局部横向滚动，不裁掉后续列。
- 不增加装饰性统计卡、默认展开的原理面板、无业务意义的动效或另一套文件资源中心。

## 已检查的实现与边界

项目没有 `docs/architecture.md`、`docs/know-how.md`、`PRODUCT.md` 或根级 `DESIGN.md`。上下文来自当前渲染页面、`src/r6-app.js`、`src/r6.css`、`server/app.py`、`docs/R6/preview/adapter.prod.js`、生成脚本及相关 QA。旧实施计划仅用于了解既有约束，未把其历史状态当作当前事实。

生产页面由 `tools/build_r6_frontend.py --prod` 生成 `src/r6.html`、`src/r6.css`、`src/r6-app.js`。真实适配器还覆写资源预算、空状态等渲染入口，正式实施必须同时调整生成来源及对应适配层，不能只改生成结果，也不能回退真实 API 接线。

预览文件完全独立：`shell.css` 为当前生产 CSS 的快照，`icons.js` 为当前应用 SVG 路径的摘录。预览业务数据与操作均在内存中，不 fetch、不写 localStorage、不访问日志/凭据/数据库。正式接入时只迁移呈现，删除预览状态选择器和示例数据。

## 功能保留与去向

| 现有能力 | 新设计中的去向 / 正式接入约束 |
| --- | --- |
| 日志源搜索、状态筛选、刷新 | 列表工具条；真实过滤、轮询与请求时序保留 |
| 日志源状态、归档量、索引覆盖 | 列表独立列；继续来自真实回执，不根据示例或 UI 推断 |
| 多目录映射、默认规则、文件匹配、排除与扫描深度 | 四步向导的目录映射步骤；稳定 ID 与字段完整保留 |
| 持续、定时、快照及协议降级 | 采集策略；选项必须由实际协议能力控制 |
| 新增、编辑、预检、暂停/继续 | 单一创建入口、详情及行操作；真实保存/动作完成后才显示成功 |
| 凭据引用、主机身份验证、访问范围 | 连接与策略表单；安全策略不因删文案而降低 |
| 409 冲突、失败恢复、未保存输入 | 表单常驻错误、保留输入、返回或明确放弃；不得用静默覆盖代替 |
| 存储登记、浏览文件库、预检、不可直接迁移物理根目录 | 存储页签、对象设置及现有文件库跳转；原有库及权限维持唯一所有权 |
| 缓存详情、重建规则结果、归档索引阅读 | 缓存页签/对象详情；正式接入继续使用真实文件及缓存 ID，不把源 ID 当缓存 ID |
| 运行记录、导出 | 运行记录页签；正式导出使用原有真实数据链路 |
| 资源预算 | 资源设置对话框；保留 5 项当前可编辑预算，其余实际只读项和固定读写块大小 |
| SSE、Worker、IndexedDB、权限和文件 provider | 保持原适配/引擎边界；本次只调整采集呈现 |

预览没有实现生产文件库导航、真实主机预检、后端权限/冲突或完整资源预算写入。这些属于正式实施与后端回归，不能把本地演示成功当作验收。
